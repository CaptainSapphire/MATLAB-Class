Helpful reminders
Use help functionName or doc functionName when you are unsure how a function works.

log(x) is the natural logarithm; log10(x) is the base-10 logarithm.

Use exp(x) for (e^x).

sin, cos, and tan expect radians. Use sind, cosd, and tand when the given angle is in degrees.

MATLAB analyzes matrix columns by default. Use the second input, such as mean(A,2), when you need a result for each row.

A random sample will usually be close to, but not exactly equal to, its target mean and standard deviation.
