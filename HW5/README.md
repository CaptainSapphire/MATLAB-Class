Homework 5: MATLAB Practice Problems (Chapter 3)
Purpose
This assignment gives you practice using MATLAB to solve and clearly communicate engineering calculations. You will apply MATLAB commands and built-in functions while completing the assigned practice problems.

What to Submit
Complete Practice Problems 3.1-3.14 in the Practice Problems PDF.
Write your solutions in a MATLAB script file.
At the beginning of each problem, include a comment with the problem number. For example:
% Problem 3.1 (a)
Save your completed file as R148_HW5_Firstname_Lastname.m.
Upload the completed .m file to Canvas by the posted deadline.
Requirements
Complete all problems from 3.1 through 3.14.
Use meaningful variable names. Do not overwrite MATLAB built-in function names, such as sin, max, or min.
Include comments where requested and clearly identify each problem number using % Problem #.
Display final numerical answers clearly, including appropriate units.
Round numerical answers to 3 significant figures. If the leading digit is 1, use 4 significant figures.
Submit only your MATLAB code file(s). You do not need to submit screenshots, separate output files, or handwritten work.
Run your entire script before submission. It should run from top to bottom without errors.
