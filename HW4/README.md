# Homework 4: MATLAB Practice Problems
Purpose
This assignment gives you practice using MATLAB to solve and clearly communicate engineering calculations. You will apply MATLAB commands and built-in functions while completing the assigned practice problems.

## What to Submit
Complete Practice Problems 2.10–2.21 in the Practice Problems PDF. <br>
Write your solutions in a MATLAB script file.<br>
At the beginning of each problem, include a comment with the problem number. For example:<br>
% Problem 2.10 (a)<br>
Save your completed file as R148_HW4_Firstname_Lastname.m.<br>
Upload the completed .m file to Canvas by the posted deadline.<br>

## Requirements
Complete all problems from 2.10 through 2.21.<br>
Use meaningful variable names. Do not overwrite MATLAB built-in function names, such as sin, max, or min.<br>
Include comments where requested and clearly identify each problem number using % Problem #.<br>
Display final numerical answers clearly, including appropriate units.<br>
Round numerical answers to 3 significant figures. If the leading digit is 1, use 4 significant figures.<br>
Submit only your MATLAB code file(s). You do not need to submit screenshots, separate output files, or handwritten work.<br>
Run your entire script before submission. It should run from top to bottom without errors.<br>
